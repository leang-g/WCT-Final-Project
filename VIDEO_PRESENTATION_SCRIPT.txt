PART 2: TECHNICAL CODE EXPLANATION (FOR YOUR TEACHER)
================================================================================

1. GLOBAL STATE MANAGEMENT: src/context/AppContext.jsx
--------------------------------------------------------------------------------
- Purpose: Acts as the single source of truth across the entire app.
- Key Responsibilities:
  * Persistent authentication and session management via localStorage.
  * Multi-account management (switching between multiple challenge accounts).
  * Tab navigation routing ('home', 'pricing', 'rules', 'dashboard', 'help').
  * Purchase gate interceptor (triggerGetFunded).

2. REQUEST-ANIMATION-FRAME ENGINE: src/components/common/AnimatedCounter.jsx
--------------------------------------------------------------------------------
- Purpose: High-performance number animation without layout shift or crashes.
- How it works:
  * Uses requestAnimationFrame with a cubic-bezier easeOut curve (1 - (1-t)^3).
  * Safely validates inputs with Number.isFinite to ensure zero NaN crashes.
  * Formats currencies and percentage signs dynamically.

3. CIRCULAR SVG GAUGES: src/components/dashboard/DashboardOverview.jsx
--------------------------------------------------------------------------------
- Purpose: Visual compliance gauges for Daily Loss and Drawdown limits.
- How it works:
  * Uses normalized SVG circle mathematics:
    Circumference = 2 * PI * radius ~ 100.
    strokeDasharray = `${percentage}, 100` with stroke-linecap round.
  * Dynamically updates based on real-time account drawdown and risk buffers.

4. 3D CARD FLIP MATRIX: src/components/Pricing.jsx
--------------------------------------------------------------------------------
- Purpose: Interactive comparison between Phase 1 (Eval) and Phase 2 (Funded).
- How it works:
  * Built using Framer Motion (animate={{ rotateY: isFlipped ? 180 : 0 }}).
  * Uses Tailwind CSS 'preserve-3d' and 'backface-hidden' utility classes.

5. RISK GUARD & POSITION SIZER: src/components/dashboard/CalculatorModal.jsx
--------------------------------------------------------------------------------
- Purpose: Pre-trade risk calculation for CME Futures.
- How it works:
  * Uses exact CME contract multipliers: NQ ($20/point), ES ($50/point), 
    CL ($1,000/point), GC ($100/point).
  * Calculates maximum allowed contracts based on trader risk tolerance and stop loss.

PART 3: QUICK TEACHER Q&A CHEAT SHEET
================================================================================

Q: "Why did you choose React + Vite instead of standard HTML/CSS?"
A: "Vite provides instantaneous Hot Module Replacement and tree-shaken production 
    bundles. React allows a component-driven architecture where state—such as 
    account balances, active positions, and authentication—is reactively 
    synchronized across all views."

Q: "How is user data persisted across page reloads?"
A: "We implemented persistent localStorage synchronization inside AppContext.jsx. 
    When an account is provisioned, reset, or modified, it is serialized to JSON 
    and restored on application startup."

Q: "How did you design the institutional fintech visual aesthetic?"
A: "We used Tailwind CSS to build a custom dark obsidian design system (#080A0F) 
    with luminous neon-emerald (#00F59B) and warm gold (#C59A45) accents, combined 
    with glassmorphism (backdrop-filter: blur), ambient SVG glow orbs, and spring 
    physics animations."
