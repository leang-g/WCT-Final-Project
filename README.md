# Apex Trading – Prop Firm Website (Educational Simulation)

A multi-page frontend website for a fictional prop trading firm, built with HTML, CSS, JavaScript, Bootstrap 5, and Chart.js.

## Pages
- **Home** (`index.html`) – Hero, how it works, testimonials.
- **Pricing** (`pricing.html`) – Plans, pricing calculator (slider).
- **Rules & FAQ** (`rules.html`) – Trading rules and accordion FAQ.
- **Dashboard** (`dashboard.html`) – Simulated trading stats and balance chart.
- **Login** / **Sign Up** – Forms with client-side validation.
- **Contact** – Simulated contact form.

## Technologies
- Bootstrap 5.3.2 (CDN)
- Bootstrap Icons (CDN)
- Chart.js 4.4.0 (CDN)
- Vanilla JavaScript

## How to Run
1. Clone or download the project folder.
2. Open `index.html` in any modern browser.
3. Navigate using the navbar.

## Notes
- All “Buy Now”, login, and form submissions are simulated. No data is sent anywhere.
- This project is created for educational/demo purposes only.
